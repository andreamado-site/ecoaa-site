# ECOAA — Laboratório de Ecologia Aquática e Aplicada

Repositório do website do ECOAA. A versão visual aprovada é a versão 7, com estrutura de conteúdo e painel de edição da versão 8.

## Publicação

O site é estático e poderá ser hospedado no GitHub Pages a partir da branch `main`, pasta `/ (root)`. Os arquivos do site (incluindo `index.html`, `conteudo.js` e `assets/`) ainda precisam ser enviados.

## Manutenção

O arquivo `editor.html` é uma ferramenta local de edição; **não deve ser publicado no GitHub Pages** enquanto não houver controle de acesso. Para atualizar o conteúdo, usar o editor localmente e enviar apenas os arquivos públicos necessários.
